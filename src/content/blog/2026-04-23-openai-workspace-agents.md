22 апреля 2026 OpenAI представила workspace agents в ChatGPT. Это общекомандные агенты, которые выполняют повторяемые end-to-end задачи: собирают контекст из подключённых систем, следуют процессам команды, просят подтверждение там, где нужно, и передают работу между инструментами. Функция доступна в research preview на планах Business, Enterprise, Edu и Teachers. До 6 мая 2026 — бесплатно, потом OpenAI переходит на credit-based pricing.

Workspace agents OpenAI называет эволюцией Custom GPTs. Разница техническая: Custom GPT отвечает на отдельный запрос в чате, workspace agent непрерывно работает в облаке, запускается по расписанию или триггеру, использует подключённые приложения и доступен всей команде. Существующие Custom GPTs можно конвертировать в workspace agents напрямую, отдельной миграции для владельцев не потребуется.

Создание простое. В боковой панели ChatGPT описываешь желаемый workflow естественным языком — билдер собирает agent со skills, доступами к календарям и базам знаний. Дальше agent можно запустить по расписанию, поделиться ссылкой с коллегами или разместить в общем каталоге workspace'а. Каталог видят все сотрудники — это канал распространения внутренних AI-инструментов без внешних развёртываний.

Пример из OpenAI. Собственная sales-команда компании использует agent, который собирает детали из заметок звонков, проводит ресёрч по аккаунту, квалифицирует новых лидов и готовит черновики follow-up писем прямо в инбоксе менеджера. Представители тратят меньше времени на сбор информации и больше — на общение с клиентами.

Что дальше. OpenAI обещает новые триггеры для автоматического старта работы, расширенные дашборды по эффективности, поддержку большего числа бизнес-инструментов и workspace agents в приложении Codex. Конкретных дат компания не называет — релизы пойдут «в ближайшие недели».

Контекст. Анонс вписывается в общий сдвиг OpenAI в сторону B2B. На этом же поле давит Anthropic с Claude Code и Claude Cowork, Microsoft с Copilot-агентами и Google с Agentspace. Разница workspace agents от конкурентов — фокус на доле рынка внутри ChatGPT, где 3+ млн разработчиков и десятки миллионов пользователей ChatGPT Enterprise уже работают ежедневно. OpenAI использует существующую аудиторию вместо того, чтобы строить отдельный продукт.
