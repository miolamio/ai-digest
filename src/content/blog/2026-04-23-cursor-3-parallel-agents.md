2 апреля 2026 года команда Cursor выпустила третью версию редактора. Это не обновление, а пересборка IDE вокруг AI-агентов. Подписка стоит 20 долларов в месяц. Релиз называют прямым ответом на рост доли Claude Code среди инструментов для разработчиков.

Главное изменение — окно Agents. В нём запускается несколько агентов одновременно, каждый работает над своей задачей в рамках одного проекта. Раньше Cursor подсказывал код в активном файле; теперь параллельные агенты одновременно правят разные участки кодовой базы. Переключение между ними идёт через Agent Tabs: вкладки открывают диалоги агентов рядом, как сессии в терминале. Разработчик ведёт несколько веток работы в одном окне и сравнивает результаты.

Тяжёлые задачи уходят в Cloud Agents. Агент выполняется не локально, а на серверах Cursor, чтобы не нагружать машину разработчика и ускорить шаги с длинным контекстом. Такой режим подходит для рефакторинга на уровне репозитория или прогонов тестов, когда ответ нужен быстрее, чем даёт ноутбук.

Design Mode меняет способ вносить правки в интерфейс. Разработчик открывает приложение в браузере, кликает по элементу и оставляет комментарий — агент получает указание и вносит изменения в код. Это убирает шаг с поиском нужного компонента и описания правки текстом: место правки задаётся прямо в UI.

Смена парадигмы заметна в том, что Cursor перестал быть инструментом автодополнения. Автокомплит остаётся, но центр продукта сместился в сторону одновременной работы нескольких агентов. Редактор становится оркестратором задач, а не помощником при наборе кода. Такой дизайн сближает Cursor с подходом Claude Code, где агент самостоятельно ведёт задачу от постановки до коммита, и уводит IDE от модели «один человек — один курсор — один файл» к модели «один человек — несколько параллельных агентов — один репозиторий».

Открытых вопросов по релизу остаётся несколько. Материал источника не уточняет лимиты на число параллельных агентов в окне Agents, объём квоты Cloud Agents внутри подписки и список фреймворков, с которыми работает Design Mode. Также не указано, какие модели подключены по умолчанию и можно ли выбрать сторонние. Для команд, которые уже используют Cursor 2, важен будет порядок миграции настроек и правил проекта — об этом в разборе данных нет.

Подписка за 20 долларов сохраняет цену прежних тарифов, поэтому барьер входа для текущих пользователей не растёт. Для новых команд Cursor 3 задаёт практический вопрос: стоит ли переходить на мульти-агентный воркфлоу или держаться привычного автокомплита, пока инструменты стабилизируются.
