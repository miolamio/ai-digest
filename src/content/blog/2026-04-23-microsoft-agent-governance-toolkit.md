Microsoft 3 апреля 2026 года опубликовала Agent Governance Toolkit — открытый набор для управления автономными AI-агентами. Пакеты доступны бесплатно на GitHub и PyPI. Разработчики получают готовый слой контроля над агентами без самописных обёрток над аудитом и политиками доступа.

Набор состоит из семи пакетов на нескольких языках программирования и покрыт более чем 9500 тестами. Ядро — движок политик с субмиллисекундным временем отклика, криптографические идентификаторы агентов и изоляция среды выполнения. Toolkit подключается к LangChain, OpenAI Agents, Haystack и Azure, поэтому команды могут добавить governance-слой в действующий стек без переписывания пайплайнов агентов.

Отдельный блок — автоматизация соответствия нормативам. Toolkit сопоставляет действия агентов с требованиями EU AI Act, HIPAA и SOC2 и собирает артефакты для аудита. Microsoft ориентирует продукт на стартапы и компании в регулируемых отраслях: здравоохранение и финансы, где агентные сценарии упираются в требования к журналированию, подтверждению личности и разделению сред. Криптографические идентификаторы позволяют отличать действия конкретного агента от действий оператора, а изоляция среды выполнения ограничивает доступ к данным и внешним API по политике.

Публикация под открытой лицензией на GitHub и PyPI снимает привязку к Azure: набор можно использовать с агентами OpenAI или локальными моделями через LangChain и Haystack. Для команд, которые уже выстраивают агентные продукты, появляется общий язык описания политик и соответствия, который не нужно изобретать самостоятельно под каждый стандарт.
