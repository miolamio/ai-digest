21 апреля 2026 OpenAI выпустила ChatGPT Images 2.0 — новую модель генерации изображений `gpt-image-2`. Доступ открыт всем пользователям ChatGPT, Codex и API. Это первое крупное обновление после `gpt-image-1.5` в декабре 2025-го. По данным компании, в ChatGPT уже создано больше миллиарда изображений за время жизни предыдущих моделей.

Главное отличие новой версии — качественный текст в изображениях. Модель сначала планирует раскладку, потом рендерит. Результат — читабельные надписи без искажённых букв, которые портили все предыдущие генераторы. Поддержка не-латинских скриптов: японский, корейский, китайский, хинди, бенгальский. Для плакатов, инфографики, манги и локализованного маркетинга это значит реальное применение, а не экспериментальные картинки.

OpenAI описывает новые возможности как «thinking capabilities». Модель умеет искать в вебе свежую информацию, генерировать до 8 изображений на один промпт и проверять собственный вывод. Это меняет workflow: вместо цикла «генерация → оценка → новый промпт» пользователь получает сразу готовый набор. Поддерживаются разные aspect ratios (горизонтальный, квадрат, вертикальный) и резолюция до 2K. Knowledge cutoff модели — декабрь 2025, что важно знать при промптах про свежие события или персоны.

Контекст рынка. OpenAI догоняет Google Nano Banana 2 (в другом названии — Gemini 3 Pro Image), которую Google выпустил в феврале 2026 с аналогичной фишкой «dense text в картинках». По тестам VentureBeat, `gpt-image-2` точнее воспроизводит UI-скриншоты и пачки связанных изображений, чем модель Google. Для продуктовых команд это значит: генерация мокапов, слайдов, скриншотов для документации — теперь входит в ChatGPT без сторонних инструментов. Для маркетинга — многоязычные ассеты без отдельного дизайнера.

Доступ. Images 2.0 работает по текущему ChatGPT-плану без отдельной цены за модель. В API тариф тот же, что у gpt-image-1.5. Интеграция в Codex позволяет встраивать генерацию в автоматизированные пайплайны. Ограничения по частоте запросов OpenAI не раскрывает, но сообщает об ускорении генерации вдвое против предшественника.

Для разработчиков практический эффект простой. Один API теперь покрывает три задачи: скриншоты интерфейса, многоязычные плакаты и мини-комиксы из нескольких панелей. Без отдельных моделей и без ручной пост-обработки текста.
